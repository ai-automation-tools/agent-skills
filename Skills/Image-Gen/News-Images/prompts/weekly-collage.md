# Weekly News Collage

> Shape: **Collage** (6-panel grid, portrait). Read `../SKILL.md` → *Shared conventions* first; this file holds only what's specific to the weekly collage.

Create a vertical cartoon-style news collage summarizing the **major U.S. news stories from the previous completed week**, then save, email, and publish it.

## Period & research
- Resolve the **previous completed Monday–Sunday week** in the user's locale to exact absolute start and end dates; use those throughout the run.
- Research **six** major U.S. news stories from that week via web search. Choose nationally relevant, visually distinct stories that represent the week; prefer recurring/consequential stories over one-off minor updates.

## Layout
- Portrait, **1024 × 1536** (2:3), matching the Daily/Monthly collage archive.
- **6 equal square panels, 3 rows × 2 columns**, clean borders between panels. Balanced, readable.
- No extra canvas height, footer, or poster stretch beyond 1024 × 1536.

## Content
- One distinct story per panel; each panel a self-contained mini-scene.
- Each panel carries **3–8 words** of embedded contextual text identifying its story (see Embedded text rules in `../SKILL.md`).

## Timestamp
- Small professional date-range stamp in the **bottom-right corner** of the whole image (outside the boxes if space allows).
- Format: **MMM D-D, YYYY** — if the week crosses months, use **MMM D - MMM D, YYYY**.

## Save
- Filename: `Weekly-News-Collage_<YYYY-MM-DD>_to_<YYYY-MM-DD>.png` (use the week's start/end dates).
- Save to the output location the user specifies; default to the current working directory and report the full path.

## Email (optional)
- Only if the user asks. Subject: `Weekly News Collage for <MMM D-D, YYYY>`
- Plain text: `Attached is the Weekly News Collage for <MMM D-D, YYYY>.`
- HTML: `<p>Attached is the <strong>Weekly News Collage</strong> for <MMM D-D, YYYY>.</p>`
