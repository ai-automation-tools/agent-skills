# Daily News Collage

> Shape: **Collage** (6-panel grid, portrait). Read `../SKILL.md` → *Shared conventions* first; this file holds only what's specific to the daily collage.

Create a vertical cartoon-style news collage summarizing the **major U.S. news stories from the previous day**, then save, email, and publish it.

## Period & research
- Resolve **yesterday's** absolute date in the user's locale; use that exact date throughout the run.
- Research **six** major U.S. news stories from yesterday via web search. Choose nationally relevant, visually distinct stories.

## Layout
- Portrait, **1024 × 1536** (2:3).
- **6 equal square panels, 3 rows × 2 columns**, clean borders between panels. Balanced, readable.
- No extra canvas height, footer, or poster stretch beyond 1024 × 1536.

## Content
- One distinct story per panel; each panel a self-contained mini-scene.
- Each panel carries **3–8 words** of embedded contextual text identifying its story (see Embedded text rules in `../SKILL.md`).

## Timestamp
- Small professional date/time stamp in the **bottom-right corner** of the whole image (outside the boxes if space allows).
- Format: **MM/DD/YYYY 11:59 PM**

## Save
- Filename: `Daily-News-Collage_<M-D-YY>.png` (use yesterday's date, e.g. `Daily-News-Collage_7-6-26.png`).
- Save to the output location the user specifies; default to the current working directory and report the full path.

## Email (optional)
- Only if the user asks. Subject: `Daily News Collage for <Month D, YYYY>`
- Plain text: `Attached is the Daily News Collage for <Month D, YYYY>.`
- HTML: `<p>Attached is the <strong>Daily News Collage</strong> for <Month D, YYYY>.</p>`
