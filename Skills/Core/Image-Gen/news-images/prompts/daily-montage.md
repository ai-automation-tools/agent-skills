# Daily News Montage

> Shape: **Montage** (single unified scene, landscape). Read `../SKILL.md` → *Shared conventions* first; this file holds only what's specific to the daily montage.

Create a single landscape cartoon-style news montage summarizing the **major U.S. news events from the previous day**, then save, email, and publish it.

## Period & research
- Resolve **yesterday's** absolute date in the user's locale; use that exact date throughout the run.
- Research **six to eight** major U.S. news stories from yesterday via web search. Choose nationally relevant, visually distinct stories.

## Layout
- Landscape, **1536 × 1024** (3:2).
- **One unified montage scene — not panels.** No grid, boxes, panel borders, comic strips, or numbered sections.
- Use a cohesive editorial environment: a chaotic newsroom, command center, map table, city square, control room, or newspaper front page come to life. Understandable at a glance.

## Content
- Weave all selected stories into one continuous scene as signs, screens, documents, maps, props, crowds, vehicles, weather effects, scoreboards, podiums, charts, or symbolic objects.
- Embed **2–8 word** labels naturally throughout the scene (see Embedded text rules in `../SKILL.md`).

## Title & date
- Place a readable title naturally in the scene (newsroom wall, ticker board, newspaper masthead): **THE DAY IN REVIEW**
- Include the exact date: **MMM D, YYYY**

## Save
- Filename: `Daily-News-Montage_<M-D-YY>.png` (use yesterday's date, e.g. `Daily-News-Montage_7-6-26.png`).
- Save to the output location the user specifies; default to the current working directory and report the full path.

## Email (optional)
- Only if the user asks. Subject: `Daily News Montage for <Month D, YYYY>`
- Plain text: `Attached is the Daily News Montage for <Month D, YYYY>.`
- HTML: `<p>Attached is the <strong>Daily News Montage</strong> for <Month D, YYYY>.</p>`
