## Why this exists

The skill's Template A and Template B sections were originally written from reading sender *source code*, without a live email to check against (the Gmail MCP tool available at the time only exposed search/snippets, not full message bodies). Once `gmail_get_message` shipped, pulling this real email surfaced a third template (C) the skill didn't have at all, and two real bugs in how it renders. Keeping the raw HTML here means the next person tightening this skill starts from evidence, not another cold read of the source.
