# readme-builder-mfs — Skill-Data

## What the skill does

[`readme-builder-mfs`](../../../../Skills/Documentation/readme-builder-mfs/SKILL.md) builds a complete, professional README **end to end** — from the root logo hero header through the footer — that renders flawlessly in both GitHub and Obsidian using pure native markdown. It also styles every non-root README (the one at the root of `docs/` and each folder/subfolder) with a lighter centered emoji-title header, and wires them into a **navigable tree** (root → docs → each section) with leftmost-link tables. It favors clean, text-first layouts and adds a diagram only when it genuinely clarifies — never by default. For just the top header block, use its companion `readme-header-mfs`.

## About this folder

Image assets used to demonstrate the output of the skill — the professional, cross-platform (GitHub + Obsidian) README style it produces.
