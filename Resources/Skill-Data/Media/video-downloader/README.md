# Skill-Data — video-downloader

Supporting material for the [`video-downloader`](../../../../Skills/Media/video-downloader/SKILL.md)
skill. Kept here rather than inside the skill folder so the portable skill stays lean —
see `CLAUDE.md`'s "Two folders people confuse" note.

## What lives here

Nothing yet. The skill's own `SKILL.md` already carries its quick start, flag reference,
troubleshooting section, and provenance notes — there's no bulky example output (a
downloaded video) worth checking into a docs repo.

## When to add something here

- A sample yt-dlp error log worth keeping as a reference for a new failure mode, once one
  turns up that the **Troubleshooting** section in `SKILL.md` doesn't already cover.
- A screenshot of the cookie-extraction flow, if that step ever needs a visual walkthrough.
