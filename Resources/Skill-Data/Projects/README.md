---

Empty until a project skill needs demo assets. The layout mirrors the skills tree one-for-one:

```text
Skills/Projects/cronsole/<skill>/          the portable unit — installed
Resources/Skill-Data/Projects/cronsole/<skill>/   bulky exemplars — never installed
```

The split exists so a skill stays small enough to copy anywhere. Anything a skill reads **at
runtime** belongs inside the skill folder under `references/` or `scripts/`; anything that only
proves the skill works, or shows a reader what good output looks like, belongs here.
